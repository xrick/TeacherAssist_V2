```
原始 → 四階段 → 五階段（目前）
```

### 目前架構：五階段（含圖片）

根據 `ppt_service_v2.py` 檔案開頭的註解和實作：

```
五階段流程（含圖片）：
┌─────────────────┐    ┌─────────────────┐    ┌─────────────────┐
│ Stage 1         │    │ Stage 2         │    │ Stage 3         │
│ TemplateAnalyzer│ →  │ ContentGenerator│ →  │ContentOrganizerV2│
│   (0-10%)       │    │   (10-45%)      │    │   (45-65%)      │
└─────────────────┘    └─────────────────┘    └─────────────────┘
                                                      │
┌─────────────────┐    ┌─────────────────┐           ↓
│ Stage 5         │ ←  │ Stage 4         │ ←─────────┘
│ SlideBuilder    │    │ ImageEnricher   │  
│   (85-100%)     │    │   (65-85%)      │
└─────────────────┘    └─────────────────┘
```

| Stage | Role | 功能 |
|-------|------|------|
| **1** | `TemplateAnalyzer` | 分析 PPTX Template 結構 |
| **2** | `ContentGenerator` | LLM 擴展使用者輸入（產生 visual_suggestion） |
| **3** | `ContentOrganizerV2` | 組織內容到 Template 結構 |
| **4** | `ImageEnricher` | 圖片搜尋與注入（Pexels API） |
| **5** | `SlideBuilder` | 建構最終 PPTX（整合 Layout Engine） |

### 發現：前後端存在版本差異

| 層級 | 顯示/設計 | 實際執行 |
|------|----------|----------|
| **前端 UI** | **4 階段** | 顯示 4 個進度指示器 |
| **後端 API** | **5 階段** | 實際執行 5 階段（含圖片） |
| **後端 Service** | **5 階段** | PPTServiceV2 執行 5 階段 |

### 前端 (ProgressMonitor.tsx)

前端 UI 設計為 **4 階段主流程 + 後處理階段**：

```typescript
// 主要 4 階段（用於進度指示器）
const mainStages = [
  { key: "template_analysis", name: "分析模板", progressStart: 0 },
  { key: "content_generation", name: "生成內容", progressStart: 10 },
  { key: "content_organization", name: "組織結構", progressStart: 50 },
  { key: "pptx_building", name: "建構簡報", progressStart: 80 },
];

// 後處理階段（不在主進度指示器中）
const stageNames = {
  // ...主流程
  adding_images: "🖼️ 自動配圖",        // 額外顯示
  generating_script: "📝 生成教學稿",   // 額外顯示
  completed: "✅ 完成",
};
```

**問題**：前端缺少 `image_enrichment` 階段的映射！

### 後端 (generation.py + ppt_service_v2.py)

後端實際執行 **5 階段**：

```python
# generation.py 註解
"""
使用新的 5 階段流程（含圖片）：
1. template_analysis - 分析 Template 結構
2. content_generation - LLM 擴展使用者輸入
3. content_organization - 組織內容到 Template 結構
4. image_enrichment - 注入圖片（可選）
5. pptx_building - 建構最終 PPTX
"""
```

後端 SSE 進度事件：
```
template_analysis (0-10%)
content_generation (10-40%)
content_organization (40-60%)
image_enrichment (60-80%)  ← 前端沒有對應！
pptx_building (80-100%)
```

### 不一致問題

| 後端 Stage 名稱 | 前端 stageNames 映射 | 狀態 |
|----------------|---------------------|------|
| `template_analysis` | ✅ 有 | OK |
| `content_generation` | ✅ 有 | OK |
| `content_organization` | ✅ 有 | OK |
| `image_enrichment` | ❌ **缺少** | **問題** |
| `pptx_building` | ✅ 有 | OK |
| `adding_images` | ✅ 有（但與 image_enrichment 不同） | 混淆 |

**關鍵問題**：
1. 後端發送 `image_enrichment`，但前端 `stageNames` 沒有對應
2. 前端有 `adding_images` 但後端沒有發送這個 stage
3. 進度指示器只顯示 4 個圓點，但實際有 5 個階段

### 修復建議

#### 選項 A：將前端更新為 5 階段

```typescript
// 更新 mainStages 為 5 階段
const mainStages = [
  { key: "template_analysis", name: "分析模板", progressStart: 0 },
  { key: "content_generation", name: "生成內容", progressStart: 10 },
  { key: "content_organization", name: "組織結構", progressStart: 40 },
  { key: "image_enrichment", name: "配置圖片", progressStart: 60 },  // 新增
  { key: "pptx_building", name: "建構簡報", progressStart: 80 },
];

// 更新 stageNames
const stageNames: Record<string, string> = {
  template_analysis: "🔍 分析模板",
  content_generation: "✨ 生成內容",
  content_organization: "📋 組織結構",
  image_enrichment: "🖼️ 配置圖片",  // 新增
  pptx_building: "🏗️ 建構簡報",
  generating_script: "📝 生成教學稿",
  completed: "✅ 完成",
};
```

#### 選項 B：保持 4 階段但修正 stage 名稱對應

如果希望 UI 保持簡潔（4 個進度圓點），可以將 `image_enrichment` 合併顯示到 `pptx_building` 階段。

### 總結

| 項目 | 現狀 |
|------|------|
| **後端設計** | 5 階段（含 ImageEnricher） |
| **前端 UI** | 4 階段（缺少 image_enrichment 映射） |
| **一致性** | ❌ 不一致 |
| **影響** | 當 `image_enrichment` 進度事件到達時，前端顯示為未知階段 |

**建議**：將前端更新為 5 階段以保持一致性。
