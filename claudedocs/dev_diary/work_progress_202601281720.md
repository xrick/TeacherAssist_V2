## 任務 2：模板文字定義來源追蹤

### 目標
根據截圖 `refData/images/ppt_template.png` 中顯示的模板畫廊，追蹤每個模板卡片的名稱、描述、標籤文字從何處定義。

### 追蹤結果

#### 資料流向
```
backend/data/templates/*.json        ← 描述與標籤定義位置
  ↓
TemplateService._create_metadata()   ← 讀取 JSON，名稱從檔名自動生成
  (backend/app/services/template_service.py)
  ↓
GET /api/v1/templates                ← API 回傳
  (backend/app/api/routes/templates.py)
  ↓
templateAPI.list()                   ← 前端 API client
  (frontend/src/api/client.ts)
  ↓
TemplateGallery.tsx                  ← 前端渲染
```

#### 模板 JSON 定義檔對照
| 模板名稱 | 定義檔案 |
|----------|---------|
| Professional Corporate | `backend/data/templates/professional_corporate.json` |
| Education Basic | `backend/data/templates/education_basic.json` |
| Nature Artistic | `backend/data/templates/nature_artistic.json` |
| Industrial Tech | `backend/data/templates/industrial_tech.json` |
| Modern Clean | `backend/data/templates/modern_clean.json` |
| Pastoral Style | `backend/data/templates/pastoral_style.json` |
| Creative Colorful | `backend/data/templates/creative_colorful.json` |

#### 關鍵發現
- **模板名稱**不在 JSON 中，由 `_create_metadata()` 從 `.pptx` 檔名自動生成（底線→空格，title case）
- **描述文字與標籤**定義在同名 `.json` 檔案中
- **預覽圖片路徑**也在 JSON 中指定

### 狀態
已完成。
