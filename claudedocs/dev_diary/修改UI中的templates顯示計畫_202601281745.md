## 三、預覽圖片設計規格

### 技術規格
- **尺寸**：400 x 225 px（16:9，與現有一致）
- **格式**：PNG，sRGB
- **生成方式**：Python PIL（Pillow），延續現有 `create_preview_images.py` 的做法
- **輸出目錄**：`backend/data/templates/previews/`

### 設計原則
- 以簡化的 wireframe 風格呈現簡報版面結構
- 色彩要符合各模板 description 中提到的配色
- 不含文字，純粹用色塊、線條、幾何圖形表達風格特徵
- 需一眼就能區分不同模板的視覺差異

## 五、注意事項

1. **PPTX 缺少**：`strategic_consulting.pptx` 和 `visionary_story.pptx` 目前不存在。
   - 預覽圖可以先生成
   - 但模板若無 PPTX 檔，`TemplateService._scan_templates()` 是以 `.pptx` 為主掃描，可能不會列出這兩個模板
   - 需確認 `template_service.py` 的掃描邏輯是否需要調整（讓 JSON-only 的模板也能被列出），或是後續補上 PPTX 檔

2. **`visionary_story.json.json` 雙副檔名**：`_create_metadata()` 尋找的是與 PPTX stem 同名的 `.json` 檔。如果 PPTX 為 `visionary_story.pptx`，則 JSON 應為 `visionary_story.json`，必須先修正檔名。

3. **舊的生成腳本**：`create_preview_images.py` 目前只有 4 個函式（education_basic, modern_clean, creative_colorful, nature_artistic），缺少 professional_corporate 和 industrial_tech。這兩張現有的預覽圖可能是手動或其他腳本生成的。新腳本需涵蓋全部 5 個。

4. **不修改程式碼**：本計畫純粹為資料層操作（JSON、PNG、檔名），不涉及 Python 服務邏輯或前端元件的修改（除了 `create_preview_images.py` 生成腳本本身）。
